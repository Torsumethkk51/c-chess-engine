# ♟️ C Chess Engine

A high-performance chess engine written in **C**, focusing on memory efficiency and bit-level optimizations.

> [!IMPORTANT]
> **Status:** Under Active Development ⚒️  
> Currently focusing on core board representation and move generation logic.

## 🚀 Features
*   **Bitboard Engine:** Leverages 64-bit integers to represent piece positions for lightning-fast bitwise operations.
*   **Board State Management:** Efficient handling of piece placement, turn tracking, and basic board visualization.

## 🏗️ Technical Architecture
To achieve maximum performance, this engine utilizes:

*   **Language:** Pure **C (C11 standard)** for zero-overhead execution.
*   **Data Structure:** **Bitboards** (using `uint64_t`) to allow the CPU to calculate moves using parallel bitwise logic.
